## 1. À qui s’adresse ce manuel

Ce manuel est destiné aux **apporteurs d’affaires** (commerciaux indépendants, étudiants, freelances) qui présentent **Gagnez des avis** aux commerçants et tous professionnels ayant l'utilité des avis et ce partout en France.

Vous n’êtes **pas salarié** : vous êtes rémunéré à la **commission** sur les abonnements des professionnels que vous apportez, via un **code partenaire** personnel.( obligation d'avoir un statut juridique à jour).

**Ce que vous avez reçu (ou allez recevoir) :**

- vos identifiants de connexion (e-mail + mot de passe) ;
- ce manuel ;
- un contrat d’association commerciale (à signer séparément).

## 2. Ce que vous vendez (rappel produit)

**Gagnez des avis** aide un établissement (commerce ou artisan) à obtenir **plus d’avis Google** de façon simple et conforme.

### Le parcours côté professionnel

1. Le professionnel crée son compte et renseigne le **lien Google** « Écrire un avis » de son établissement.
2. Après le passage d'un client satisfait, le professionnel envoie une **invitation SMS ou e-mail** (prénom + lien).
3. Le client ouvre une page d’invitation. S’il bloque pour rédiger, le client saisi des mots clés et  l’outil propose des **suggestions de texte** basés sur ce qu’il a vécu.
4. Le client **publie lui-même** sur Google — **vous ne publiez jamais à sa place**.



### Offres professionnel (TTC)


| Offre   | Prix mensuel | Invitations / mois | Prix annuel (1×) |
| ------- | ------------ | ------------------ | ---------------- |
| Starter | 39 €         | 200                | 420 €            |
| Growth  | 79 €         | 450                | 852 €            |
| Scale   | 129 €        | 750                | 1 392 €          |


- **Inscription gratuite** : 5 invitations de découverte (SMS ou e-mail), sans carte bancaire.
- **Quota partagé** : SMS et e-mail consomment le même stock d’invitations.
- **Votre code partenaire** : **−15 %** sur la **1re facture payante** du professionnel.



### Promesses à tenir


| À dire                                  | À ne jamais dire                          |
| --------------------------------------- | ----------------------------------------- |
| Le client publie lui-même               | « On poste les avis pour vous »           |
| Aide à la rédaction (brouillons)        | « L’IA écrit l’avis final à votre place » |
| Plus d’avis récents = plus de confiance | « On garantit 5 étoiles »                 |
| Invitation ciblée (SMS ou e-mail) après un vrai passage | « On spamme votre fichier clients »       |

## 3. Votre rémunération



### Principe

Vous touchez un **pourcentage du montant TTC** de chaque facture payée par vos professionnels (mensuelle **ou** annuelle).

Le pourcentage dépend du **nombre de professionnels abonnés** que vous avez apportés (stock actif) :


| Professionnels abonnés | Commission |
| --------------------- | ---------- |
| 1 à 19          | 40 %       |
| 20 à 34         | 45 %       |
| 35 à 49         | 50 %       |
| 50 à 74         | 55 %       |
| 75 et plus      | 60 %       |




### Exemples (Starter 39 € TTC / mois)

La commission est toujours un **% du TTC réellement encaissé** (pas du prix catalogue).

**1re facture** avec votre code (−15 %) : le professionnel paie **33,15 €** (39 € − 15 %).


| Votre stock | Taux | Commission 1re facture |
| ----------- | ---- | ---------------------- |
| 1–19        | 40 % | **13,26 €** (40 % × 33,15 €) |
| 20–34       | 45 % | **14,92 €**            |
| 35–49       | 50 % | **16,58 €**            |


**Mois suivants** (plein tarif 39 €) :


| Votre stock | Taux | Commission / mois / professionnel |
| ----------- | ---- | -------------------------- |
| 1–19        | 40 % | **15,60 €** (40 % × 39 €)  |
| 20–34       | 45 % | **17,55 €**                |
| 35–49       | 50 % | **19,50 €**                |


*Même logique sur une facture annuelle : % du montant TTC réellement payé (après −15 % si c’est la 1re facture).*

### Versement

- Vos commissions apparaissent dans l’espace commercial, **mois par mois**.
- Statut affiché : **« en attente de versement »** ou **« versée »**.
- Le versement effectif et sa périodicité sont définis dans votre **contrat d’association** (coordonnées bancaires, seuil minimum, etc.).

## 8. Prospection : le carnet partagé

Le carnet évite que **deux commerciaux démarchent le même établissement** sans le savoir.

### Consulter le carnet

1. Onglet **Prospection**
2. Liste des établissements déjà visités : nom, ville, statut, dernier passage, commercial

**Filtres utiles :**

- Recherche (nom, ville, téléphone)
- Statut
- Ville
- Case **« Masquer refus / déjà client / compte créé / concurrent »** (cochée par défaut)

[Image 14 Liste prospection avec filtres](14-prospects-liste.png)




### Avant d’entrer dans un établissement

1. Ouvrez **Prospection** sur votre téléphone
2. Recherchez le nom ou la rue
3. Si une fiche existe avec **« ne pas reprospecter »** → **ne pas insister** (refus, déjà client, concurrent…)



### Enregistrer une nouvelle visite

1. Cliquez **Nouvelle visite**
2. Remplissez :
  - **Commerce** * (obligatoire)
  - Ville, CP, adresse, téléphone
  - **Résultat** * (voir tableau ci-dessous)
  - **Réponse du professionnel** * (ce qu’il a dit — soyez factuel)
  - Notes internes (optionnel)
  - **Rappel prévu** si « Intéressé » ou « Rappeler plus tard »
3. **Enregistrer la visite**


| Statut                   | Quand l’utiliser                  | Reprospecter ? |
| ------------------------ | --------------------------------- | -------------- |
| Intéressé / à relancer   | Accueil favorable, pas signé      | Oui            |
| Rappeler plus tard       | « Revenez mardi »                 | Oui            |
| Compte créé              | Inscription faite avec votre code | Non            |
| Déjà inscrit            | Compte existant détecté           | Non            |
| Refus                    | Pas intéressé                     | Non            |
| Absent / fermé           | Porte close                       | Oui            |
| Concurrent déjà en place | Utilise un autre outil            | Non            |
| Autre                    | Cas particulier                   | Selon note     |


[Image 15 Formulaire « Enregistrer une visite »](15-nouvelle-visite.png)




### Doublon détecté

Si l'établissement existe déjà, le système affiche les **fiches similaires**.  

- Lisez l’historique → **ne pas reprospecter** si refus / client / concurrent  
- Sinon : **Créer quand même** si c’est un nouveau passage légitime

[Image 16 Alerte doublon](16-doublon.png)




### Fiche détail et nouveaux passages

Ouvrez une fiche → **Historique des passages** (qui, quand, quoi).  
Pour un **retour** chez un professionnel « Intéressé » :

1. Ouvrir la fiche
2. Section **Ajouter un passage**
3. Mettre à jour le statut + commentaire
4. **Enregistrer le passage**

[Image 17 Fiche prospect + historique](17-fiche-prospect.png)




### Détection automatique « Compte existant »

Si le téléphone saisi correspond à un professionnel déjà inscrit, la fiche affiche **Compte existant détecté**.  
Passez le statut à **Compte créé** ou **Déjà inscrit** pour éviter les doublons.

## 10. Organisation d’une journée type



### Avant de sortir (10 min)

- [ ] Connexion `/sales/login`
- [ ] Copier votre **lien d’inscription**
- [ ] Parcourir **Prospection** → fiches « Rappeler plus tard » du jour
- [ ] Noter 1–2 établissements cibles (zone, type)



### Sur le terrain (2–3 h)

Pour **chaque établissement** :

1. Vérifier le carnet (pas déjà visité / refus)
2. Pitch 20 s → 60 s si intérêt
3. Proposer inscription sur place ou envoi du lien
4. **Enregistrer la visite** immédiatement (même si refus — c’est essentiel)

Objectif débutant réaliste : **5 à 10 portes** / demi-journée, **1 inscription** / session.

### Après la tournée (15 min)

- [ ] Compléter les fiches manquantes
- [ ] Envoyer les liens WhatsApp aux intéressés
- [ ] Programmer les rappels (statut + date dans le carnet)
- [ ] Vérifier **Mes professionnels** → relancer les « Jamais payé »



### Checklist 1re semaine


| Jour  | Objectif                                                      |
| ----- | ------------------------------------------------------------- |
| J1    | Connexion, copier le lien, 5 portes                           |
| J2–J3 | 10 portes / jour, 100 % des visites saisies dans le carnet    |
| J4    | 1ère relance des intéressés                                   |

## 12. Interdits et bonnes pratiques



### Interdit (sanctions : exclusion du réseau)

- Promettre des **5 étoiles garanties**
- Dire qu’on **publie à la place** du client
- Proposer **cadeau / réduction** en échange d’un avis
- **Spam** SMS / e-mail ou fichiers clients achetés
- Contourner votre code (inscription sans code pour « faire gagner » le professionnel — vous ne serez pas rattaché)
- Insister sur un établissement marqué **ne pas reprospecter**



### Bonnes pratiques

- Toujours **enregistrer la visite**, même en cas de refus
- Utiliser **votre lien** (`?code=…`) à chaque inscription
- Relancer les **Jamais payé** dans la semaine
- Rester factuel dans les **notes** (pas d’insultes, pas de données sensibles inutiles)
- En cas de bug ou question : **[acdigitalstudio@outlook.fr](mailto:acdigitalstudio@outlook.fr)**

## 14. FAQ

**Mon professionnel s’est inscrit sans mon code — que faire ?**  
Contactez le support **rapidement** avec le nom de l'établissement et la date. Sans code à l’inscription, le rattachement n’est pas automatique.

**Quand commence ma commission ?**  
À la **1re facture payante** (après les 5 invitations gratuites ou dès souscription directe).

**Un Professionnel paie annuel : je touche combien ?**  
Le même **% du TTC réellement payé**. Ex. Scale 1 392 € sans remise → 40 % = 556,80 €. Si c’est la **1re facture** avec code −15 %, la base est 1 392 × 0,85 = 1 183,20 € → 40 % = **473,28 €**.

**Je vois « en attente de versement » — c’est normal ?**  
Oui. Le passage à « versée » se fait lors du virement défini contractuellement.

**Puis-je voir les invitations envoyées par mes professionnels ?**
Non. Vous voyez le **statut d’abonnement** et les **paiements**, pas l’activité d’invitation détaillée.

**Le carnet est-il privé ?**  
Non, il est **partagé** entre commerciaux : c’est voulu pour éviter les doublons.

**Comment obtenir de l’aide technique pour un professionnel ?**  
Orientez-le vers son espace **Compte** et **Abonnement**, ou écrivez à [acdigitalstudio@outlook.fr](mailto:acdigitalstudio@outlook.fr) en copie.

**À quoi servent les comptes démo ?**  
À s’entraîner et à montrer le parcours client sans publier d’avis. Voir la [section 13](#13-comptes-démo-entraînement).
